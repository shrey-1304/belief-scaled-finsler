# Data Source

## Dataset

The experiments in this repository were conducted using publicly available datasets.

| Dataset | Purpose | Source |
|----------|---------|--------|
| MultiWOZ 2.2 | Task-oriented dialogue generation and sequence modeling | https://github.com/budzianowski/multiwoz |

---

## Preprocessing

The dataset was preprocessed to construct conversational context-response pairs suitable for sequence modeling. Standard tokenization and train-validation-test splits were applied where appropriate.
